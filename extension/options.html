Setup

Welcome! The extension talks to your devices through a small local companion. Install the prerequisites below, then run the one-time auto-setup — you'll only do this once.

Prerequisites

Node.js v18+Runs the backend server
nodejs.org
AppiumMobile automation server
npm install -g appium
Android driverFor Android devices
appium driver install uiautomator2
iOS driver (macOS)For iOS simulators
appium driver install xcuitest
ADB (Android)Via Android Studio or
Platform Tools
Xcode (iOS/macOS)iOS simulator support
From the Mac App Store

Install the companion

cd ~/Downloads
bash install_appium_locators_inspector.sh
cd %USERPROFILE%\Downloads
install_appium_locators_inspector.bat

Then

Reload the extension

Open chrome://extensions, find Appium Locators Inspector, and hit reload so it picks up the companion.

Connect a device

Open the popup, start your servers, pick a platform and device — and you're inspecting.

Environment check

Not sure everything's ready? Run a quick preflight and we'll check the companion, backend, and platform tooling for you — think of it as an Appium doctor.

Troubleshooting

Something not working? Here are the fixes for the issues people hit most. If you're still stuck, the logs at ~/.appium_locators_inspector/native-host.log usually tell the story.

IssueSolution
"Native messaging host not found"Re-run the auto-setup installer, then reload the extension.
Servers won't startCheck logs in the popup. Ensure Node.js is installed.
Appium not foundnpm install -g appium
No Android devicesRun adb devices in a terminal. Enable USB debugging.
No iOS simulatorsBoot a simulator in Xcode. macOS only.
